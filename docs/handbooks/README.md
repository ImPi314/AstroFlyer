# Review handbooks

These are the review guides as presented at the zeroeth to third reviews. They describe parts of the project
that were never built or measured (a C++ kernel, a PyQt6/OpenGL console, Sundman regularisation, a FreeFlyer
comparison and speed-up figures). For what AstroFlyer actually is and its measured accuracy, see
[astroflyer/TECHNICAL_REPORT.md](../../astroflyer/TECHNICAL_REPORT.md); §7 lists the corrections.
